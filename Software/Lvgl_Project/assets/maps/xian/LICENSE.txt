This derived offline vector database contains OpenStreetMap data.
The xian-cycle.bgraph routing database is derived from the same OSM sources.
The xian-color.btiles map images are produced from those sources, with original
cartography. OSM attribution must remain visible; see the OSM copyright page
below for database and produced-work attribution requirements.

Original source query: overpass-query.txt. Provenance and checksums: manifest.json.
Source endpoint: https://overpass.private.coffee/api/interpreter
This is original OSM vector data; no offline bulk download of rendered OSM tiles.

The supplied GPX is a planned route derived from road connectivity. It is not
a recorded ride or a guarantee of current access/road conditions. PC rider
positions are simulated along that route. Elevation data is not supplied.
