## 接入方式

`src/ui/pages/ui_boot_page.c` 包装独立 `ui_boot_motion.c` 模块，沿用原启动页 API，并新增 `ui_boot_page_is_complete()`。四个动画 C/H 文件位于同目录，现有 CMake 源码收集会自动编译。

路由进入启动页时播放动画并创建 20 ms 完成检查定时器。查询动画完成后，顶层黑色矩形从透明渐变至不透明，得到启动页淡出；遮罩全黑后沿用 BOOT_COMPLETE 事件进入首页，先将首页入场组件设为透明，再撤去黑色遮罩的视觉覆盖。事件队列满时重试。

首页按状态栏、身份卡、累计数据、骑行/导航按钮、最近骑行、历史记录、我的成就、系统设置八组顺序入场。同排两个按钮同时出现，每组使用 360 ms 缓出曲线，组间错开 60 ms，总时长约 780 ms。透明度从 0 增至 255，translate_y 从 12 px 回到 0，不改变布局坐标或字体大小。普通 opa 会随子对象绘制递归相乘，不启用 opa_layered，不引入全屏组透明合成缓冲。

路由离开启动页时暂停动画、删除完成检查定时器。黑色矩形在首页入场时保持可点击但视觉透明，接管触摸直到最后一组组件落位，然后隐藏并重置空闲计时。过渡中跳转到其他页面会取消入场动画、恢复各组件透明度和位移、移除交互锁；返回首页使用正常完成布局，重复开机才重新播放入场。页面销毁时动画自动释放定时器和上下文。

首次启动、重启 ACK 成功、关机状态下按电源/编码器/返回唤醒均进入同一启动路由。启动与淡入淡出期间按键、控制中心和触摸手势不会提前切换页面或显示覆盖层；遮罩接管触摸，避免首页尚未完全显现时误触组件。减少动效设置下直接显示完成态并进入首页；自动息屏不会遮住启动及过渡。

现有应用在进入启动路由前完成页面和服务初始化。动画结束仅表示演出完成；将来若初始化迁移到后台任务，应加入真实资源准备条件，不能将进度轨道当作资源准备完成的依据。所有动画与路由 API 在 LVGL 线程调用。

## 验证与边界

应用集成测试覆盖首次启动保留到 5 秒、淡出后进入首页、首页分组入场期间按键和触摸隔离、过渡结束后恢复交互、关机后开机、重启、减少动效、离页暂停和 BOOT_COMPLETE 单次发送；也验证淡出和入场被路由打断后不会残留黑色遮罩，组件透明度和位移恢复正常。在全帧及 40 行部分缓冲两种模式下运行。
