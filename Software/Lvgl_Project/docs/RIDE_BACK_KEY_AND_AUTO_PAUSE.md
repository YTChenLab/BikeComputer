# 返回键骑行控制与自动暂停

## 交互定义

骑行态统一复用返回键，不引入新的页面按钮：

| 输入 | 行为 |
| --- | --- |
| 单击返回键 | 返回上一级；在结束确认状态中取消结束并恢复此前 Dynamic Card |
| MENU 双击 | `HOME` 开始准备、`GPS_READY` 确认开始、`RIDING`/`PAUSED` 手动暂停或恢复 |
| BACK 长按 700 ms | `RIDING` 或 `PAUSED` 时进入结束骑行确认 |

板端接入合同参数为 25 ms 消抖、BACK 长按 700 ms、POWER 长按 2000 ms、MENU 双击窗口 250 ms；当前 STM32 工程的 `InputTask` 仍是 10 ms 占位循环，这些时序尚未由现有固件实现或验证。板端接入后由输入服务识别时序，UI 只接收已识别结果，不重复计时。BACK 双击、MENU 长按和编码器按键长按已取消，不触发旧动作。PC 用 Esc/右键模拟 BACK 单击，F5 模拟 MENU 双击；F6 按下/释放模拟 BACK 长按开始/结束，忽略系统重复按键消息，并在窗口失焦时结束已开始的长按。完整边界见 [实体输入架构与队列契约](输入架构重构_20261009.md)。

## 自动暂停

第一版采用带迟滞和时间确认的速度规则：

- 速度持续不高于 `1.0 km/h` 达 3 s：自动暂停；
- 自动暂停后，速度持续不低于 `3.0 km/h` 达 1 s：自动恢复；
- 手动暂停属于用户明确覆盖，不允许速度变化自动恢复；
- 暂停/恢复仍经 `ui_command_service` 异步命令闭环，UI 不直接伪造硬件成功状态。

阈值目前是产品原型参数。真机阶段应结合 GNSS 抖动、轮速传感器质量和隧道/室内丢星情况重新标定，必要时优先采用轮速有效性而非单独依赖 GNSS 速度。

## Bottom Interaction Surface 状态

所有骑行反馈都替换统一底部表面的内容，不创建独立弹窗：

```text
MENU 双击 -> 命令处理中 -> 手动暂停/恢复结果 -> 恢复此前 Dynamic Card
低速 -> 命令处理中 -> 自动暂停结果 -> 恢复此前 Dynamic Card
长按 -> 结束确认 -> 正在结束 -> 正在保存 -> 骑行总结
```

命令失败或超时也进入同一 Surface 的失败反馈，并保留原骑行状态。

暂停、恢复的 Pending/Success/Failed 与结束确认统一使用 `DOCK_ID_RIDE`。业务优先级、抢占和恢复栈只由 `ui_dock` 保存；`ui_bottom_surface` 不再为 Dock 卡维护第二套恢复关系。这避免了保存阶段 Storage 卡移除后，Surface 又恢复已删除 Ride 卡的状态分裂问题。

Surface 的出现、内容刷新和恢复采用无离屏图层的几何过渡：

- 首次出现：从居中的较窄、较矮状态短距离上移并展开到完整尺寸；
- 原位刷新：通过 `x/y/width/height` 做轻微收缩回弹，内容宿主原位替换；
- 消失：轻微下移并向中心收缩，动画结束后隐藏；
- 动画只改变统一 Bottom Interaction Surface，不创建额外浮层。

不允许在整个 Surface 或 441×206 级别的内容 Host 上使用
`transform_scale` 或整体 `opacity` 动画。LVGL 会为这类效果申请 ARGB8888
中间图层；单层约需 `441 × 206 × 4 = 363,384 Byte`，会耗尽当前 1 MiB
LVGL 堆，也不符合后续 STM32/SDRAM 显存预算。按钮级小范围按压缩放仍可保留。

## 输入层边界

输入路由边界：STM32 InputService 负责采样和时序识别；Input Router 将内部事件显式映射为标准 12 字节 `ui_physical_input_event_t` 后入队；UiTask 调用 LVGL 的实体输入消费接口。UI 页面不区分 PC 与 STM32 来源，PC SDL 直接注入同一标准语义，不维护第二套手势识别器。

## PC Simulator 验证

1. 在 Home 点击“开始骑行”，在 GPS Ready 后点击 `GO`。
2. 单击鼠标右键或短按 `Esc`，确认返回上一级。
3. 按 `F5` 注入一次 MENU 双击，确认骑行控制动作只执行一次；在骑行/暂停状态分别确认手动暂停/恢复。
4. 按 `F6` 并释放，确认 BACK 长按进入结束确认；系统重复键盘消息不得改变动作次数。
5. 在确认状态单击返回，确认一次操作即可取消并恢复此前 Dynamic Card。
6. 再次长按并选择 `YES`，确认依次显示结束、保存状态并进入骑行总结。
7. 骑行中按 `S` 切换为停止，等待 3 s，确认自动暂停；再次按 `S`，等待 1 s，确认自动恢复。

## 自动化覆盖

- `ui_physical_input_test`：实体键语义映射、取消手势无动作、编码器边界和非法记录；
- `ui_pc_input_test` / `ui_pc_input_hal_test`：PC 快捷键注入、单次菜单双击、F6 生命周期和 SDL 页面行为；
- `ui_auto_pause_test`：低速延时、自动恢复迟滞、手动覆盖与非骑行态复位；
- `ui_core_logic_test`：PC 停止模拟、暂停原因透传、结束确认到保存/总结状态链。
