# UI V2 交互实现说明

## 已实现页面

- P0 启动页：启动后 1.6 秒自动进入首页。
- P1 仪表盘：保留既有实时骑行数据页。
- P2 导航：本地路线示意、剩余距离、预计到达、累计爬升与缩放交互。
- P3 骑行总结：保存、上传占位、返回主页。
- P4 个人中心：用户统计、贡献记录、骑行详情和成就提示。
- P5 设置：八项菜单、上下选择、系统信息入口。
- P6 系统信息：设备、固件、序列号、空间与健康状态。
- P7 快捷控制：无线、定位、亮度、声音和骑行开始/暂停/结束。
- 电源菜单与独立黑屏关机页。

## PC 模拟器操作

| 输入 | 映射 |
| --- | --- |
| 鼠标左滑 / `Left` | 首页进入导航；导航返回首页 |
| 鼠标下滑 / `M` | 打开快捷控制 |
| 鼠标上滑 / `M` | 关闭快捷控制 |
| `Up` / `Down` | 编码器旋转：导航缩放、设置/快捷控制选择 |
| `Left` / `Right` | 快捷控制左右选择 |
| `Enter` | 编码器按下：执行当前动作或导航菜单 |
| `Esc` 或 `Backspace` | 返回首页/关闭快捷控制 |
| `[` / `]` | 快速进入个人中心 / 设置（PC 调试快捷键） |
| `P` | 模拟电源键短按：关屏；再次按 `P` 或 `Enter` 唤醒 |
| `O` | 模拟电源键长按：电源菜单 |

## 数据和硬件边界

- P2 是离线路线示意，不包含真实 GNSS 定位、路径规划、网络地图瓦片或导航服务。
- “上传数据”仅给出明确占位提示，尚未接入账户、网络和云端 API。
- 成就目前使用屏幕提示；真机音效需要另行接入音频外设驱动和音频资源。
- 所有 PC 示例值均为演示数据。真机移植时应由数据服务层更新 Dashboard 和各页面状态，不能直接把演示值用于业务逻辑。

## 字体资源

`tools/generate_ui_font.py` 从 `assets/fonts_src/MiSans-Semibold.ttf` 生成
`src/ui/fonts/ui_font_misans_ui_20.c`。它只包含当前 P0-P7 所需的中文字符，英文与数字通过既有 MiSans 英文数字字体回退，从而避免完整中文字库占用 Flash。

修改或新增任何中文界面字符串后，请重新运行该脚本并用 UCRT64 构建。
