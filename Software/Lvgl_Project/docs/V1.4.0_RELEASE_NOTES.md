# BikeComputer LVGL UI v1.4.0 版本迭代日志

- 归档日期：2026-10-02（Asia/Shanghai）。
- 版本：v1.4.0；上一归档版本：v1.3.1。
- 基线提交：`0370e1ee55b305644dc6ae7d35944badb0876f33`。
- 范围：`Software/Lvgl_Project` 当前源码、资源、测试、接口示例、预览和工程文档，以及仓库版本说明。
- 内置 LVGL：9.3.0-dev；产品画布：480×854，RGB565。
- 本次发布操作更新版本元数据及迭代日志，并清理一处 Git 差异检查发现的文件末尾多余空行；归档此前已完成的功能，不增加导航功能。

## 相对 v1.3.1 的主要变化

### 视觉、布局与骑行显示

统一纯黑画布、中性灰表面、白色正文和黄色主题。首页、个人主页采用用户确认的视觉基准；统计数字与单位基线、长文本、活动矩阵、功能入口和卡片尺寸得到调整。全局使用 16 px 产品底边距与 72 px 底部操作行高，性能诊断作为半透明顶层覆盖。

速度进度恢复平行四边形分段并按速度档位着色；心率/功率区间条加厚，区间编号采用较大的粗体字。新增巡航/训练/爬坡方案、六格字段编辑、布局预览、滚动条和偏好持久化。

### 开机与交互动效

纳入现有 PRTS 两幕开机动画、开机结束淡出及首页分组入场。胶囊焦点、控制中心和底部容器采用连续阻尼弹簧，支持重定目标、反向、触摸取消和生命周期清理；骑行和减少动态效果策略保留。本次不重做开机动画或调整动画参数。

### 数据、业务与保存

骑行数据携带字段能力、有效性、来源、采样时间、会话和有效期，区分真实零值与缺失值。报告使用真实时间轴和可用数据；缺少位置时明确无轨迹，首页最近记录与个人活动统计来自历史模型。

完善开始、暂停、恢复、结束确认、保存和失败重试，以及关屏继续记录和安全电源流程。异步命令反馈按匹配 ACK 更新状态，避免迟到结果覆盖新状态。历史采用后台提交、幂等恢复、CRC/备份、独立累计统计和后台分页，配置采用后台保存与反馈。

### 页面与输入接口

增加独立设备与传感器页面、收藏路线空态、16 项累计成就及相关入口；设备扫描未接入时明确提示，上传服务未接入时不显示成功。增加个人区间编辑、五键/编码器消抖与映射、STM32 任务安全数据邮箱、异步命令完成和存储后端接口。

### 模拟器与验证资源

增加约 3 英寸尺寸估算、50%/原始尺寸切换与 +/- 校准；内部 480×854 画布和输入坐标保持一致。保存实际 LVGL 页面预览、动效审核图和可编译硬件接口示例。物理尺寸为估算值，需要按电脑显示器实测校准。

## 本次发布验证

- 使用现有 Anaconda/MSYS2 UCRT64 工具链执行 CMake/Ninja 构建：成功。
- 执行当前工程全部既有 CTest：33/33 通过，包含完整应用全帧和部分缓冲模式。
- 核对 6 个 PRTS 开机源文件：本次发布整理前后 SHA-256 一致。
- 本次不增加新测试，不安装依赖，不改动导航功能实现。

此前保存的全帧/分块渲染对照属于已有验证证据，本次不将它们写成重新执行的结果；详见 [全局底部与对齐规范](全局底部与对齐规范_20261002.md)及相关阶段报告。

## 当前功能边界

- 导航已有局部路线、定位、转向、弱定位和重算显示接口；真实地图读取、完整目的地/路线预览、独立算路和偏航重算仍待开发。
- 收藏路线当前为独立空态；设备页尚未接入真实 BLE 扫描、配对和设备管理后端。
- STM32/ESP32 的显示、触摸、传感器、GNSS、TF 和电源板级驱动及联调不属于本次发布验证；不据 PC 结果承诺真机 60 FPS 或续航。
- 全量原始运动日志、FIT/GPX 导出、云端服务、完整升级恢复等仍需后续开发；报告采样不能替代完整日志。
- 构建产物、本机运行存档及仓库中其他未跟踪的硬件资料、STM32 工程和安装包不纳入本次 UI 版本提交。

本版本作为后续导航开发前可恢复的 Git 基线，使用 `v1.4.0` 标签定位。
