# BikeComputer LVGL UI v1.5.0 版本更新日志

- 归档日期：2026-10-05（Asia/Shanghai）。
- 上一版本：v1.4.0，提交 `511f005af35ba55e346810816082e98cb308f4ea`。
- 范围：LVGL UI 源码、导航与离线地图服务、PC 后端、资源、测试、接口示例和工程文档。
- 内置 LVGL：9.3.0-dev；画布：480×854，RGB565。
- 本次将 10 月 3—4 日已有开发成果归档为 v1.5.0，并整理版本元数据、资源管理与发布流程。此次发布整理不改写统计算法或补做板级驱动。

## 相对 v1.4.0 的主要变化

### 导航与离线地图

新增导航中心、地图选点、目的地确认、路线准备与预览、引导、快捷操作、结束确认及到达流程。地图与常规交互坞统一为 464×540 和 464×226；编码器、触摸、返回层级、浏览与回中、长名称和禁用状态统一处理。

接入西安城区真实 OSM 数据：彩色 RGB565 离线瓦片、道路图 A* 选点规划、后台加载和缓存，以及来源、许可、覆盖范围和校验清单。彩色包为 89,284,362 字节；基础矢量包、道路图与地点索引分别为 24,801,004、5,544,128 和 7,057,748 字节，四项合计约 120.82 MiB。大型地图对象使用 Git LFS，不直接放入普通 Git 历史。

PC 位置仍沿路线回放。真实道路图不保证所有交通限制、道路开放状态或地点入口已经核实；高精度瓦片覆盖也不等于西安全行政区域。

### 地点搜索与输入

新增 5,348 条真实地点/道路记录、91,205 条检索键，支持中文候选、拼音和首字母检索。搜索与算路请求分离，包含后台查询、取消、超时、旧结果过滤和焦点保持。

横向字母拨盘替代开发早期的两页 QWERTY，支持触摸选字、拖动吸附和编码器输入。无有效结果时隐藏候选并扩展地图；有效候选到达后再展开列表，退出恢复常规导航布局。

### 骑行、导航与交互细节

开始导航接入搜星、GO 和记录 ACK；已有骑行或暂停会话复用记录，跨页继续记录。结束导航或到达页确认完成时停止并保存骑行，保留取消、停止 ACK 等待、保存失败重试和重复提交保护。

设置/设备页面使用较大的选中卡片与实心黄色液体选择，统一行高、文本和滚动条。修复编码器反向边界、自动滚动与触摸滚动混淆、长按地图的底图漂移，以及连续保存后再次选路线的图层内存不足。首页总览使用独立刷新反馈。

## 发布验证

发布副本使用既有 D 盘 UCRT64 工具链完成 1,285 步干净构建，无编译警告或错误；当前全部 41 项 CTest 通过，用时 188.16 秒。测试覆盖数据/服务、导航/搜索/地图解码，以及应用和离线导航的全帧、局部刷新流程。

本轮还检查版本一致性、Git 差异、地图对象 SHA-256 和提交范围。历史文档中的帧数、性能采样和截图对照为当时的验证记录，不能当作本轮重新执行的结果。

新加入的 GitHub Actions 工作流会在 Windows runner 上重新构建、测试和打包；只有版本号与标签一致且测试成功，才创建 GitHub Release。云端结果以实际 Actions 状态为准，工作流存在本身不等于云端验证通过。

## 已知限制与后续优先项

- 传感器更新间隔过大时，报告累计可能将最新有效心率/功率等值扩展到整个空窗，需要明确逐字段有效区间。
- 独立传感器共用全局采样时间戳，较晚到达但较新于本字段的数据可能被拒绝，需要完善多源提交约定。
- 下降高度直接累计负向海拔变化，抖动可能增加下降量，需要滤波和阈值策略。
- 地图服务的失败/超时路径仍存在约 28 KiB 的局部帧对象栈占用，移植 STM32 前必须处理并测量任务栈。
- 骑行过程中主要保留 RAM 状态，结束时保存；报告抽样轨迹不能代替全量日志，也没有完成中途掉电恢复验收。
- 当前 LVGL 运行期断言配置关闭；C 测试断言与 LVGL 内部断言是两回事，Debug 构建不自动证明后者开启。
- STM32 FatFs、真实 GNSS、BLE、偏航重算、任务资源预算、续航与长时间稳定性仍需实机验证；本版不代表整机商用成熟。

## 获取与运行

源码建议使用 Git 克隆并执行 `git lfs pull`，随后查看 [工程 README](../README.md)。自动生成的源码 ZIP 可能只包含 LFS 指针；Release 的 Windows PC 包包含模拟器运行文件和完整地图资源，可解压后运行 `启动模拟器.cmd`。

旧 `v1.0.0`—`v1.4.0` 标签和 `release/ui-v1.4.0` 分支保留。`main` 用于集成已验证版本，`feature/navigation-ui` 保存本次开发历史；标签固定发布时的提交。操作规则见 [版本发布流程](RELEASE_WORKFLOW.md)。
