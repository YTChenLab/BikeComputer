# BikeComputer LVGL UI v1.5.1 版本更新日志

- 发布日期：2026-10-05（Asia/Shanghai）。
- 上一版本：v1.5.0，提交 `1b04b79fa1be116d9bd840c8ab8ac820d40791a6`。
- 范围：LVGL UI、导航地点/道路资源、PC 搜索适配、测试与文档。内置 LVGL 仍为 9.3.0-dev，画布 480×854。

## 搜索与导航

- 修复陕西科技大学仅命中太华路校区的问题，加入未央校区和简称/拼音别名；两个校区分别列出。`SXKJDX`、全拼或“陕科大”显示候选，`SXKJDXWY` 可缩小到未央校区。
- 离线地点/道路库由 5,348 扩大到 19,196 条，含 374,147 个检索键、2,265 条住宅分类记录。范围为新城、碑林、莲湖、灞桥、未央、雁塔与长安；高新区按雁塔/长安区界覆盖，暂不含临潼、咸阳及其他托管片区。这些数字是数据记录数，不是地点覆盖率或独立小区数量。
- 支持现有中文名称、地址、全拼及首字母索引；当前输入拨盘仍为 A–Z。候选显示行政区/已有地址，区分同名异地，优先完整地点名称；超过八条时提示细化输入。
- 每次进入搜索清空旧关键词、候选、拨盘和请求，包含快速重开和从确认/路线预览返回；同一个面板内从结果焦点返回输入保留正在输入的内容。
- 选择候选先确认落点，再显式规划；可以调整位置。区域中心与关联入口分开，陕西科技大学未央校区的默认点仍为校区地图位置，尚未可靠关联真实校门。
- 道路图与矢量底图同步扩展。彩色瓦片覆盖保持原范围，范围外使用矢量底图；损坏资源仍报告错误。保留 OSM 来源、区划、构建记录及资源 SHA-256。

## 联网接口预留

Windows PC 端预留高德输入提示接口、异步请求、七区过滤、离线/在线去重、GCJ-02 到 WGS84 的近似换算及动态中文字体回退。无配置文件或 `enabled=0` 时继续纯离线搜索；发布包只包含 `enabled=0`、空 Key 的模板。没有读取或提交个人 Key，也不创建启用配置。

网络失败保留离线结果；联网候选必须有有效坐标，确认页提示核对落点。当前只验证了解析、配置、取消、回退和无效占位 Key 的错误响应，未使用真实 Key 验收地点覆盖。有效 Key 的缩写支持、具体小区、接口权限和额度留待后续联调。

同时修复 TinyTTF 对正常缺字回退的缓存错误误报，保留原有英文字体。真正的分配失败仍报错；集成测试检查缺字替换、中文回退和英文字体解析。

## 个人主页动效

刷新、成就进度、近 30 天活动和五个功能入口统一实心黄色流体胶囊选择，复用首页/设置的现有组件。支持编码器连续移动、反向回弹、触摸、首尾循环、离开/重进和减少动效。身份卡与总数据区保持只读；选中卡片文字切为深色，嵌入徽章、进度条和活动矩阵保持数据颜色。去除大卡片按压缩放，避免为反馈额外申请变换图层。

## 发布验证

使用现有 D 盘 UCRT64/GCC/CMake/Ninja 工具链在独立发布副本完成最终干净构建，无编译警告或错误。全部 44 项 CTest 通过，用时 105.78 秒；覆盖数据/存储、索引、网络解析/配置/回退、个人主页、搜索重置，以及全帧/分块的实际地图搜索与路线流程。

最终应用集成保存 325 组全帧/分块画面，逐像素一致，其中个人主页 19 帧包含移动、反向、成就/活动/设置选中、触摸与重新进入。最终动效画面已人工查看。

7 项地图/路线/来源对象的 SHA-256 与清单一致；版本文件和系统信息一致，提交范围仅包含 UI 软件与仓库版本说明。Windows 包检查 ZIP CRC、地图与运行文件哈希、空 Key/默认关闭模板、字体版权声明及许可原件，并在移除工具链 PATH 后验证默认离线与占位配置的启动；占位配置仅验证字体初始化，不执行地点查询。未使用个人 Key。

## 边界与后续工作

- 离线 OSM 的商户、门牌、通行和入口数据不完整，不能承诺“搜哪就有”；联网补充也需要实际样本验收。GPS、地点坐标、可通行入口与道路连通性是不同问题。
- 本版联网只补充地点，路线仍由 OSM 骑行图规划；未实现完整转向限制与实时道路开放信息。找不到可规划路线时报告失败。
- GCJ-02 逆算为近似转换，未经校门实地误差验收。PC 定位仍为路线回放，不代表真实 GNSS 验收。
- 道路图约 6.65 MiB，规划临时区约 3.55 MiB；联网 JSON token 数组在 PC 上约占 48 KiB 栈，中文回退 TTF 约 7.66 MiB 常驻 PC 堆。STM32 移植仍需独立的内存、文件系统、通信和字库方案。
- v1.5.0 中统计空窗、多源时间戳、海拔抖动、掉电恢复、运行期断言及硬件性能的限制仍未全部解决，见 [上一版发布记录](V1.5.0_RELEASE_NOTES.md)。本版不是整机商用成熟性认证。

## 获取与运行

源码通过 Git 克隆并执行 `git lfs pull`。Windows PC Release 包包含运行文件、地图、空配置模板、已有中文字体及更新日志，解压后运行 `启动模拟器.cmd`。`runtime/`、个人 Key、构建缓存和本机环境不进入发布包。

`feature/navigation-ui` 保留开发提交，`main` 集成已验证版本，annotated tag `v1.5.1` 固定发布提交；旧标签不改写。GitHub Actions 会重新构建、测试并在成功后创建 Release，实际云端状态以 Actions 为准。
