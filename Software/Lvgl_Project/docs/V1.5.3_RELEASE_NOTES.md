# BikeComputer LVGL UI v1.5.3 版本说明

- 版本日期：2026-10-27（Asia/Shanghai）。
- 上一版本：v1.5.2；本版修复提交：`b80618eee09fa51d174548e8fb4000b0a8f8f6eb`。
- 范围：LVGL UI 输入映射、PC 输入适配、回归测试、版本标识和接入资料。STM32 固件、BSP、HAL、FreeRTOS、InputService、Input Router 和 ESP32 源码均未修改。
- 内置 LVGL 仍为 `9.3.0-dev`，分辨率 480×854，RGB565。

## 实体输入修复

| 输入 | v1.5.3 行为 |
| --- | --- |
| MENU SHORT | 打开原快捷控制中心，遵循导航等上下文规则 |
| MENU DOUBLE | `UI_INPUT_RIDE_TOGGLE`，执行原开始、GO、暂停或恢复 |
| BACK SHORT | 原返回、取消或关闭动作 |
| BACK LONG_START | `UI_INPUT_BACK_LONG`，骑行或暂停中进入原结束确认 |
| PREV / NEXT SHORT | 原翻页和导航上下文操作 |
| ENC_SW SHORT | 原确认操作 |
| ENCODER CW / CCW | 原焦点、数值或地图操作，按增量档数执行 |
| BACK DOUBLE、MENU LONG、ENC_SW LONG | 合法消费但不执行旧 UI 动作 |
| LONG_REPEAT、LONG_END、DOWN、UP | 无附加 UI 动作；保留既有枚举数值 |

移除 BACK 双击的旧暂停/恢复处理及队列优先分类。公共 `ui_physical_input_event_t` 仍为 12 字节，delta/time 偏移仍为 4/8；所有现有枚举编号、STM32 UI 服务接口名称和函数签名保持不变。原有页面、导航、动效、触摸和骑行状态机继续复用。

PC 的 F5 只注入 MENU 双击，忽略系统重复消息；F6 只注入配对的 BACK LONG_START/LONG_END，忽略重复和孤立释放，窗口失焦时结束已开始的长按，不生成 LONG_REPEAT。F7/F8 的旧长按入口取消。M、Esc/Backspace/右键、左右方向键、Enter、滚轮和上下方向键保持原语义用途。

## 接入文档与板端边界

文档将“BACK 以外的键双击无动作”修正为“MENU 以外的键双击无动作”，目标时序统一为 25 ms 消抖、BACK 700 ms 长按、POWER 2000 ms 长按、MENU 250 ms 双击窗口。

这些时序是板端接入合同参数，尚未由当前 STM32 固件实现或验证。当前同目录 STM32 工程的 InputTask 仍是 10 ms 占位循环，应用事件队列尚未接入 UI 标准事件。目标链路为内部采样/识别 → Input Router 显式转换 → 12 字节标准记录 → RTOS 队列 → UiTask 调用 `ui_stm32_services_handle_input_event()`；内部枚举不能直接 cast。文档删除旧 `{type,value}` 结构示例和未定义的队列函数伪代码。

UI 消费接口未发现阻塞项；完整 UITask 输入链路仍依赖 STM32 侧实现识别、路由和队列适配。v1.5.3 不是整机验收结论。

当前接入入口为 [STM32 v1.5.3 接入说明](STM32_V1.5.3_INTEGRATION.md)，详细手势规则见 [输入架构与队列契约](输入架构重构_20261009.md)。历史 v1.5.2 说明保留，历史测试数字不作为本版验证结果。
