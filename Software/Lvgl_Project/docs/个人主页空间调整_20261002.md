# 个人主页空间调整

本文件记录上一轮调整。随后用户明确要求性能信息作为半透明浮层，不占页面高度；
当前内容底边已改为 y=838，保留 16 px 产品边距。当前规范及新版预览见
[全局底部与对齐规范](全局底部与对齐规范_20261002.md)。下表与配图保留为上一轮记录。

刷新按钮增加到 38 px 高，入口图标、标题、副标题和箭头按新的卡片高度重新定位。

保持已有数据来源、操作入口、黑灰黄色主题、编码器焦点与按压动效。
