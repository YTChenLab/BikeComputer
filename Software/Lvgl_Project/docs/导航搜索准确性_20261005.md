# 导航搜索准确性改进（v1.5.1）

本阶段以 v1.5.0 为基础改进导航数据与搜索，现纳入 v1.5.1。下列阶段性验收保留原始口径，最终发布验收见 [v1.5.1 发布记录](V1.5.1_RELEASE_NOTES.md)。

## 已确认的问题

旧索引共 5,348 条记录。补充学校的查询实际只覆盖钟楼周边的一小片区域，未收录陕西科技大学未央主校区；输入 `SXKJDX` 或全拼只能匹配已有的太华路校区。截图中的名称是“太华路校区”，不是太白路。

这是数据覆盖与校区别名的问题。提高模糊匹配强度不能找到未进入地点库的校区，也不能替用户判断要去哪个同名地点。

## 本轮结果

- 学校名称、带校区的名称、首字母、全拼及常用项目检索词均建立索引。`SXKJDX`、`shanxikejidaxue`、`shaanxikejidaxue`、`SKD`、`陕科大` 能找到陕西科技大学两个校区；`SXKJDXWY`、`SKDWY` 限定未央校区。检索词不等同于学校官方简称。
- 保留“陕西科技大学（未央校区）”与“陕西科技大学（太华路校区）”两个独立候选。未央条目对应 OSM way 293805614，其原始名称“陕西科技大学西安校区”也作为别名保留。
- 结果显示类型、所在区及 OSM 已有地址。公交站、地铁站和出入口分别标识；同名公交站不挤掉同名地标。不同地址的同名地点保持独立，长名称优先保留末尾校区或分店限定词。
- 选择候选后显示地图位置与确认卡片。点击“规划路线”才开始算路；“调整位置”可以选择确认可通行的入口。根据后续交互要求，每次重新进入搜索均清空关键词、候选与拨盘位置，包括从确认/路线预览返回搜索。
- 中文名称及带空格的全拼由搜索服务支持；当前拨盘仍是 A–Z，不是中文输入法或完整门牌键盘。
- 有有效定位时，候选距离与排序参考定位点。没有有效定位时不显示虚假的当前位置距离。PC 定位仍是路线回放。
- 最多保留八个候选，超出候选容量或扫描限制显示 `8+ 地点`，应继续输入校区、地址等关键词。未知地点不猜测成另一个名称相似的目标。

## 覆盖与规模

搜索与骑行图按 OSM 区划过滤到新城、碑林、莲湖、雁塔、灞桥、未央、长安。包括雁塔和长安内的高新片区；不宣称覆盖高新区所有跨区托管片区。咸阳、临潼等范围外地点被排除。

资源外包矩形为 WGS84 `(108.63, 33.79, 109.28, 34.47)`，实际检索范围按上述区划多边形限定。矩形不代表其中所有县区都被纳入。

## 来源与重建

主数据来自 [Geofabrik 陕西快照](https://download.geofabrik.de/asia/china/shaanxi.html)，快照时间为 `2026-10-03T20:20:50Z`。下载文件 [shaanxi-261003.osm.pbf](https://download.geofabrik.de/asia/china/shaanxi-261003.osm.pbf) 为 93,509,923 字节，官方 MD5 `59156b1c907678839bfc5415f8223c11` 核对一致；SHA256 `c30ec4cbd6bc0e9ce5f6c46fdf2bd35ce915b3a6122a85cd5176b7b8f7e1b1b6`。

校区与区划另有 2026-10-05 的公开 Overpass 核验数据。中文读音继续使用原有 Unicode Unihan 17.0.0。位置和道路始终使用 WGS84；未混用高德/百度的偏移坐标，也未下载地图厂商渲染瓦片。

`navigation-sources-20261005.zip` 保存实际用于构建的区域 JSON、查询信息及区划数据，`navigation-coverage.json` 保存范围、来源摘要及限制，`SHA256SUMS.txt` 保存资源校验值。原彩色图与回放路线保留其独立来源，不把新道路图的时间写成彩色图的时间。

使用现有 Python 环境可运行 `tools/import_osm_pbf.py` 导入区域原始数据，随后使用 `tools/build_navigation_region.py` 一起生成地点、道路与矢量地图。构建会检查来源文件 SHA256、完整性标记、区划闭合、格式与节点上限，失败时不安装到原工程。后续完整更新应以完整新区域快照为基础，避免混入已删除的历史地点；更新同一对象时不保留已被删除的旧权限标签。

## 板端接口与兼容

共享 C 搜索核心不调用 LVGL、malloc 或操作系统文件 API；仍通过 `read_at` 从存储读取。BPOI0001 的 128 B 头、160 B 记录、68 B 索引不变，资源 revision 从 1 更新到 2。

revision 2 的记录扩展区：144 为入口经度 E7，148 为入口纬度 E7，152 为有效位（0 或 1），156 为保留零。显示位置与导航位置分开。新读者兼容 revision 1；旧读者不支持新 UTF-8 索引键，应一起更新软件和资源。

新道路图规划工作区为约 3.55 MiB，较旧图约 2.90 MiB 增加。PC 测试不能证明 STM32 外存、线程栈和字体预算足够，移植时仍需检查实际 SDRAM/Flash/TF 及启动读取时间。

## 必须保留的边界

32 条记录关联到地图标注入口并通过道路吸附距离检查，不代表 32 个入口已现场验证。陕西科技大学未央校区目前没有可靠关联的校门坐标，默认点是校区地图位置；前往具体校门时应使用“调整位置”。

OSM 的国内商户、门牌及通行标注并不完整。公开入口也可能临时关闭或不允许骑行。现有骑行图按已有权限保守过滤，尚未实现完整转向限制；找不到路会报告失败，不生成直线导航。

本轮已改善范围覆盖、名称检索和校区确认，不能仅凭索引数量宣称“绝大多数真实目的地全部正确”。长期达到接近成熟商业地图的覆盖，仍需要授权 POI/地址来源、更新流程与真实骑行样本验收。

## 验收

- 最终 Debug 构建通过，无编译错误或警告；43 项 CTest 全部通过，总耗时 222.31 秒，包含完整与分块刷新两种实际地图集成流程。
- 校区回归检查 `SXKJDX`、两种陕西全拼、`SKD`、中文别名和完整名称；`SKDWY`/`SXKJDXWY` 指向未央候选。检查同名公交站不隐藏钟楼地标。
- 实际道路 A* 回归从城区起点前往陕西科技大学未央位置，终点纬度大于 34.35，并满足 180 m 吸附上限，排除误去太华路的情况。此检查不等于校门现场验收。
- 应用集成验证先显示候选、确认未央位置、再发起规划；后续已改为返回搜索即清空查询。另行检查旧 revision 1 地点索引可读取。
- 补齐矢量地图汉字后，6 项字体与应用测试通过；最后针对“调整位置”取消返回、手动选点保留校区名称，再运行 6 项导航、字体及完整/分块实际地图集成测试，全部通过，总耗时 218.05 秒。
- 区划过滤、不同门牌的同名地点、不关联附近私人门、长名称保留校区、PBF 坐标符号/增量/偏移和截断失败处理均有回归。
- 地图、地点与来源包 SHA256 全部核对一致。最终候选、位置确认与路线画面保存于工作目录 `captures`，可按实际截图核对。

后续增加的搜索重置及可选联网接入见 [导航联网搜索说明](导航联网搜索_20261005.md)。上述 43 项和 6 项耗时记录属于离线覆盖更新阶段；联网与重置的验收单独记录，不能把离线测试当成真实联网效果证明。
