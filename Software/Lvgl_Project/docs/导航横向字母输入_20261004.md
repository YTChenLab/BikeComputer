# 导航横向字母输入

按用户第三张横向输入带效果图落地，使用已确认的触摸直接输入、编码器选择后按压规则。属于 1.4.0 之后的未发布内容，不提交或推送 Git。

## 布局和动画

普通导航的 464×540 地图、464×226 交互坞和 y=838 底边不变。搜索为临时状态：顶部搜索框 y=62、h=56；输入卡片始终固定在 y=654、h=184，输入期间键位不移动。无输入、仅一个字母、查找中、无结果或服务错误时，不显示候选卡片，地图 y=128、h=514。只有当前请求完成且存在有效地点时，地图压缩至 h=210，候选卡片推挤至 y=348、h=294；三条 86 px 候选及间距完全可见，更多候选独立滚动。

输入卡片显示五个字母，字母触摸区域为 84×94 px，中央黄色胶囊为 72×84 px，下方为「退格／查看结果」两个 210×56 px 按钮。使用 MiSans Heavy 40 px 的 A–Z 粗体子集，4 bpp 字形位图为 11,866 字节，另有字形描述和映射表。主刻度与每格三条小刻度连续随字母移动，中央固定短标记提供对齐基准；远处刻度和字母降低亮度。黄色胶囊使用细描边、轻微纵向明度渐变和顶部高光，结果区聚焦时转为中性灰。移除左右切页、箭头、上下三角和输入区操作说明。两个边缘复用对象补足滑动中间帧，共七个字母对象，不创建 26 个复杂按键或额外地图缓冲。

一格选字使用 120 ms 可打断位移动画，连续输入更新最新目标。胶囊沿中央对称拉伸、挤压后回弹；文字与胶囊为独立对象，字形不缩放。拖动从按下时的绝对坐标计算，不叠加重复采样、不加惯性；超过 8 px 才作为横向拖动，垂直偏移取消提交。释放后吸附到最近字母，滑动不输入。减少动效设置同样生效。

触摸拖动跨过一格时触发小幅胶囊形变，编码器选字和提交分别沿用拉伸、挤压反馈，提供视觉刻度感；未增加机械阻尼或硬件触觉反馈。候选以 300 ms 推挤并渐显，失效后以 220 ms 收回；地图尺寸由搜索进入进度和候选进度共同计算，避免两组动画争抢同一个尺寸。连续输入、快速反转、退出和重入均从当前状态衔接。旧结果可短暂保留为收回动画的画面，但立即禁用点击、编码器选择及滚动，不作为新查询的有效候选。

## 触摸、编码器和实体键

字母区和结果区共用查询、当前字母与结果选择状态。进入搜索默认控制字母区，选字不触发查询；只有输入或退格后经过 160 ms 防抖才调用现有异步搜索接口。结果返回不会切换控制区。

- 编码器：字母区旋转选择 A–Z，首尾循环；按压输入当前逻辑字母。结果区旋转选择候选，按压进入目的地和自动路线规划。
- 触摸：点击任一可见字母直接输入，左右滑动只选择。点击候选直接选地点。「查看结果」切换至结果区，「继续输入」切回字母区。没有有效结果时禁用查看结果。
- 上一项实体键：退格；下一项或菜单键：切换字母/结果控制区。仅搜索激活时承接这些语义，不改变电源、普通骑行或其他页面操作。
- 返回键：结果区先回字母区；字母区退出搜索并保留查询。退出按钮直接退出。重新进入和从路线预览返回保留查询及当前字母，不自动清空。

输入上限为 63 个 ASCII 字母，搜索框显示大写尾部与黄色光标，后端接收小写完整查询。长查询保持光标和退出按钮的边界，不将显示截断用于检索。

## 数据与板端边界

继续读取现有真实西安 BPOI 索引，支持地点拼音、首字母和原有音节匹配；不是通用中文输入法，也未新增门牌号、数字键或云端语音。空查询仅保留搜索框和字母拨盘；查找中、无结果、索引缺失、服务未接入及超时在搜索框右侧显示轻量状态，不生成空候选卡片。有效结果数量也显示在搜索框右侧，长查询按剩余宽度截断显示尾部；「查看结果」无有效结果时采用灰色禁用态。最近路线和收藏入口继续位于导航待机页。

使用原有 `ui_nav_search_register/request/cancel/submit` 异步接口。TF 检索工作线程和路线规划保持独立，晚到结果严格按 request_id 过滤。距离表示地点锚点与进入搜索时地图中心的估算直线距离，不冒充路线里程。

LVGL 输入对象在 UI 线程内更新；STM32 平台继续通过原有语义按键和 LVGL 触摸 indev 接口接入。未增加地图缓冲、网络依赖或 ESP32 运算要求，真机响应与帧率仍需实测。

## 验证

回归内容包括快速反转及 A/Z 循环、动画中按压、直接触摸字母、按住与重复采样、横向拖动不提交、垂直取消、异步焦点保持、退格、63 字符边界、搜索菜单键不启动骑行、保留查询、真实钟楼检索和道路图规划、返回尺寸恢复、快速重入与减少动效。新增空查询/一个字母/查找中/无结果/索引缺失时候选隐藏、展开中间帧、收回中旧结果禁用、候选展开反转、输入卡片固定位置，以及 A–Z 字形覆盖检查。

最终编译通过。最新代码的导航组件、交互坞、字体三个 CTest，以及全帧/局部刷新的应用集成和真实西安离线导航四个流程全部通过，共七项针对性回归。此前地点索引、导航会话/存储及硬件输入核心回归也通过。

49 组真实地图画面与 266 组应用集成画面在全帧与局部刷新间逐像素一致，共 315 组；覆盖搜索进入/退出、拨盘刻度移动、候选展开和反转等中间帧。钟楼查询返回真实 POI，选中后生成道路图路线，返回保留查询并恢复常规地图。没有缺字或绘制内存错误。

八个开机动画、首页及个人主页保护文件未改变，三份地图/道路图/地点索引资源未改变，VERSION 保持 1.4.0。最新预览与日志保存于 D 盘 `111AAABike_SpeedView/work/dial-refine`。验证属于 PC 模拟器，不代表 STM32 真机帧率或实际输入速度。
