# 模拟器尺寸与校准

PC 窗口默认按 3 英寸屏幕估算显示大小，LVGL 的内部画布始终保持 480×854。
窗口缩放只发生在 SDL 显示阶段，按钮、滑动、控制中心手势均转换回同一套 LCD 坐标。
不改变硬件 UI、字体、数据接口或启动动画。右下角性能信息继续保留。

## 操作

| 按键 | 功能 |
| --- | --- |
| F1 | 接近 3 英寸的物理尺寸预览 |
| F2 | 50% 桌面预览，240×427 |
| F3 | 原始尺寸预览，最大 480×854；桌面高度不足时自动适配 |
| + / - | 每次放大 / 缩小约 2.5%，可用主键盘或数字键盘 |

F1 模式下，+ / - 调整物理尺寸校准系数；F2/F3 模式下进入自定义缩放。
切换或校准后，偏好保存在工程的 `runtime/simulator_view.ini`，再次启动会恢复。
删除这个文件可恢复默认值，不影响骑行记录和硬件设置。
Windows 窗口标题列出模式和缩放率；只允许按键等比缩放，避免拖拽改变屏幕比例。

## 校准到实际 3 英寸

按有效显示区域对角线 3 英寸、分辨率 480:854 计算：

- 宽：约 37.34 mm。
- 高：约 66.43 mm。
- 对角线：76.20 mm。

上述尺寸不包括窗口标题栏和边框，也不包括实体屏幕的玻璃及外壳。
按 F1，用尺子量电脑上彩色画面本身的高度，再用 + / - 调到约 66.43 mm。
在另一台显示器上预览时，应再次检查校准。

SDL 自动获取的显示器 DPI 不一定可靠，尤其不能把 Windows 的缩放百分比直接当作面板物理像素密度。
因此标题以 `3in ~` 标识估算，而不是声称精确还原实物。
启动前也可指定已知的面板像素密度，例如：

```powershell
$env:UI_SIMULATOR_DPI = '110'
$env:UI_SIMULATOR_MODE = 'physical'
.\启动模拟器.cmd
```

`UI_SIMULATOR_DPI` 接受 40～600 的有效数值；未提供时使用 SDL 报告值，获取失败时回退到 96。
`UI_SIMULATOR_MODE` 可为 `physical`、`compact`、`native`，覆盖本次启动的模式。
使用手工 DPI 时，若之前校准过，可先删除 `runtime/simulator_view.ini` 消除旧校准系数。

Windows 采用 per-monitor V2 DPI awareness，减少操作系统额外放大窗口的影响；缩小采用线性采样。
电脑缩小预览会丢失部分像素细节，不能据此判断真屏的字体清晰度；审查字体时用 F3。
PC FPS 仍仅代表 PC 模拟器，不能作为 MCU 真机帧率。

依据：[SDL DPI 可靠性说明](https://wiki.libsdl.org/SDL2/SDL_GetDisplayDPI)、
[Windows DPI awareness](https://wiki.libsdl.org/SDL2/SDL_HINT_WINDOWS_DPI_AWARENESS)。
