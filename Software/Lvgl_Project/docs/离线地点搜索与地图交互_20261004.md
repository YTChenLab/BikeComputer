# 离线地点搜索与地图交互

日期：2026-10-04。属于 1.4.0 之后的未发布开发内容，本轮不提交、推送或新增 Git 标签。

本文件记录上一轮两半 QWERTY 搜索实现及数据资源。输入区、搜索布局与返回规则现由 [导航横向字母输入](导航横向字母输入_20261004.md) 替代；地图/检索格式和 STM32 接口继续适用。

## 已实现的产品行为

普通导航、路线预览和导航中，保持 464×540 地图、464×226 交互坞，底部结束位置 y=838。搜索是临时布局状态，退出后恢复原尺寸。

待机交互坞的第一项为「搜索地点」，下面保留「我的路线 / 最近使用」。触摸搜索胶囊或通过编码器进入后，搜索胶囊平滑移到上方，背景形状有弹性伸展和回弹；地图从 y=62、h=540 过渡到 y=128、h=160，地图像素与文字不压缩。地图相机暂停跟随，键盘从底部滑入。尺寸变化逐帧保持地图中心，避免连续取整导致地图漂移。

输入区使用两页 QWERTY：左半 QWERT / ASDFG / ZXCV，右半 YUIOP / HJKL / BNM；字母键 80×52，切页、退格、完成固定在底部。上方展示中文地点、类型与距当前地图中心的直线距离，距离不是规划里程。查询至少两位，可输入完整拼音、拼音片段的音节起点或首字母，例如 jiaotong、xajtdx、zhonglou；不需要先把拼音转换为逐字中文。结果最多八条，可滚动，编码器优先定位到第一个候选。

「完成」或硬件返回键先收起键盘、扩大结果列表；再次返回退出搜索。点击输入胶囊可以重新展开键盘。选中地点后，键盘和结果列表收回，地图恢复尺寸并居中标记地点，后台自动规划；成功后展示路线总览、里程与开始按钮，失败显示真实失败状态。预览返回恢复搜索与原查询，便于更换地点。长按地图、编码器中央准星选点和导航中的返回/结束确认保留。系统的减少动效设置同样作用于搜索。

## 地图拖动与文字修复

原拖动惯性将最后一次位移乘以七，缺少释放速度判断。现改为绝对触摸坐标差分，跨过 8 px 门限后应用总位移，后续仅应用实际新增位移。静止触摸不再写入位置，避免覆盖同一轮 UI 调度中的缓存重定位；应用移动前更新布局，保证读取最新位置。

使用最近 90 ms 的实际移动采样估计释放速度，速度超过 0.8 px/ms、最近移动不超过 35 ms 且采样跨度至少 20 ms 时才滑行。额外滑行最多 56 px、120 ms；精确选点不使用惯性，重新按下立即停止位置和缩放动画。

地名从真实 OSM node、way、relation 提取，学校区域与地标区域中心进入独立文字图层。标签以实际字体宽度避让，类型采用温和的学校、地标、医疗与车站颜色；边缘标签保持完整行，不显示半个汉字，超长名称省略。新类型的解码、服务校验和绘制统一支持 kind=0..7。

## 数据、TF 资源与边界

`assets/maps/xian/xian-color.btiles`：89,284,362 B（约 85.15 MiB），8,331 个瓦片、9 级 LOD。整包覆盖经度 108.78..109.15、纬度 34.12..34.46，属于西安城区矩形，不是西安全行政区。最高两档及建筑细节仍受原始数据区域限制，详见 color_manifest.json。

`xian-cycle.bgraph`：126,871 节点、213,230 有向边，5,544,128 B。新增 POI 原件同时保留原始可用道路节点信息，图规模与上一轮略有变化。

`xian-places.bpoi`：7,057,748 B（约 6.73 MiB），5,348 条地点和道路记录、91,205 条拼音/首字母索引。记录含 191 条学校、193 条地标、97 条医疗、252 条车站、157 条公园、14 条其他地点及 4,444 条道路锚点。计数是去重后的记录，不等同于独立学校数量；同名道路可能保留多个区段。地图文字层含 907 个命名 POI。具体 SHA-256、来源快照、覆盖及类型数量在两个 JSON 清单中。

新增学校来源：Overpass 2026-10-03 快照、经度 108.90..109.01 / 纬度 34.22..34.32，193 个原始记录。新增地标、医院、车站：同一快照城区范围，587 个原始记录。继续复用此前保存的两个 OSM 原件，按快照时间合并标签，避免只有几何的节点覆盖旧命名标签。OSM 数据遵循 ODbL-1.0，界面保留 OpenStreetMap 署名。

读音来源为 Unicode 官方 Unihan 17.0.0，使用 kMandarin 去除声调生成拼音，并限定常见多音字变体数量。没有安装新的拼音库。Unihan 使用 Unicode-3.0 许可；清单保存官方 URL 和下载哈希。

此版本是命名 POI/道路离线检索，不是完整门牌地址检索，不是通用中文输入法，也不保证每个学校、商店已在 OSM 中登记。当前名称所需汉字都有读音记录，但部分词的实际读音及俗称仍可能需要词组别名补充。

区域中心和道路区段中心只作为显示/检索锚点，不宣称已验证公共入口。规划继续使用真实道路图及 180 m 匹配限制，无法接入的地点明确失败；不虚构校园入口、私有道路和交通数据。PC 位置仍为 REPLAY，路线仍仅保存于本次进程。实时 GNSS、FatFs 驱动、复杂转向限制与跨重启归档属于板端后续工作。

## STM32 接口与资源分配

`ui_offline_places.h/.c` 是共享 C 核心，不调用 LVGL、malloc 或文件系统。板端给出 `ui_offline_map_io_t.read_at`、文件大小和上下文即可从 FatFs 读取同一 BPOI0001 文件。格式：128 B 头部、160 B 地点记录、68 B 排序索引；小端、WGS84 E7 整数坐标，头部及载荷 CRC 校验，长度/排序/字符串终止符检查。

索引初始化在存储任务中完成；挂载一份不可变资源包后验证一次，卸载/更换资源包必须取消查询并重新验证。单次检索先二分定位，再扫描有界候选，最多 8,192 个索引候选，保留前八条，排序兼顾精确匹配、POI 类型与直线距离。达到扫描限制时 results.limited=true，不能宣称结果已穷尽或必为全市最近地点。整个七兆索引不用加载到 RAM。

板端通过 `ui_nav_search_register()` 注册 request/cancel：request 只复制 `ui_nav_search_request_t` 至任务队列并通知存储任务，不能在 UI 回调中同步访问 TF。存储任务查询后调用 `ui_nav_search_submit()`；UI 定时器调用 tick/get 并渲染。新的请求取消旧请求，request_id 严格过滤晚到结果，超时为五秒。UI 输入有 160 ms 防抖。与导航 session 的规划请求独立，不会每输入一个字母就取消导航任务。PC 已用独立工作线程实现这一端口。

核心查询的局部工作区约 2 KiB、搜索结果与 UI 双邮箱为数 KiB 级；LVGL 键盘对象及字体需要另计。建议存储任务栈留 8 KiB，TF 读取缓存 4–16 KiB，再由板端实测峰值收紧。这是移植预算，不是已测硬件占用。现有 768×768 地图双缓冲约 2.25 MiB，PC 24 槽瓦片缓存约 3 MiB，必须放 STM32 可访问的外部存储并按真实容量调整；ESP32 的 PSRAM 不能作为 STM32 的共享 RAM。搜索不用新增全屏地图缓冲或依赖 ESP32 算力。

新增汉字已进入 MiSans 子集；真机仍需链接映射文件检查字体/代码的 Flash 或 QSPI 容量。PC 的绘制及规划时间只能用于软件回归，不作为 STM32 60 FPS 或续航承诺。

## 构建与验收

使用已有 D 盘 CMake/GCC/Python，未安装依赖。先通过地图跟手、真实西北大学标签和完整选点导航修复验证，再接入搜索。

新增核心测试覆盖全拼、首字母、音节起点匹配、无结果、损坏包、截断包、取消、晚到结果、超时和缺少后端。完整 LVGL 集成测试以真实触摸操作两页键盘，检索钟楼、生成道路图路线、验证返回保留查询、尺寸恢复、编码器、快速重入与减少动效，并捕获展开和收回的中间帧。预览返回时清除未开始的路线状态，保留定位，防止待机状态继续显示旧路线。

最终构建成功。41 个现有及新增测试用例全部验证通过：39 项 CTest 回归先整体执行、修复新增入口造成的两处旧焦点假设后复测；最后的导航会话调整又复测五项相关用例。两项真实离线导航全帧/局部刷新集成用例单独执行并保存截图，通过全部断言。46 组截图逐像素一致，包含 24 个搜索动效中间帧。没有缺字或绘制内存错误；快速重入不会残留输入阻挡。

地图跟手回归中，在 5.003 m/px 比例下，实际手指位置对应地理点误差约 6.319 m（约 1.26 px，包含缓存坐标取整），松手停住没有额外惯性漂移；长按坐标误差为零。PC 的 100 帧地图绘制采样全帧中位数 4 ms、P95 5 ms，局部刷新中位数 5 ms、P95 6 ms；选点 A* 样例约 14 ms，工作区 3,044,904 B。这些数值仅代表本次 PC 回归。

三个资源包 SHA-256 通过校验；八个开机动画、首页及个人主页保护文件未改变；目标安装文件与 D 盘开发暂存一致。Git diff --check 通过，只有原有换行格式提示。VERSION 保持 1.4.0。
