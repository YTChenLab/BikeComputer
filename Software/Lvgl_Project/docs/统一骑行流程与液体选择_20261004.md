# 统一骑行流程与液体选择

日期：2026-10-04。目标工程为 `Software/Lvgl_Project`，VERSION 保持 1.4.0，本轮未提交、推送或打标签。

## 首页

- 数据总览为只读展示，里程、时间、爬升均不进入编码器操作顺序、不跳转历史记录。
- 右上角独立刷新按钮加入操作顺序；更新已有骑行汇总，并显示旋转反馈。反馈结束前禁止重复请求。刷新保持当前页面。
- 身份入口、刷新、开始骑行、导航、最近骑行、历史记录、设备、收藏路线和设置共九个操作入口。选中采用实心黄色液体填充，文字随背景改为深色。
- 液体移动只绘制到可操作卡片内部，途经只读总览时不会出现覆盖数据的黄色拖尾。

## 设置与设备列表

- 主设置和设备列表使用 114 px 基准行高和 12 px 间距，同屏约五条完整卡片；紧凑子页面保持默认尺寸。
- 采用轻微弧线内收，最大横向位移为 18 px。主设置与设备页选中卡片横向展开到 452 px，高度为基准的 102%；其他卡片为 96.5%。选中项在 480 px 屏幕上左右各留 14 px；字号和文字方向保持不变。
- 同一选择色块的前后缘错开移动并回弹；连续旋转可从当前画面改向，不积压切换队列。
- 编码器旋转仅改变焦点和滚动位置，按压才执行操作；触摸点按执行，滑动滚动不触发开关。
- 首尾停止，不首尾循环；设置中的只读信息跳过操作焦点。右侧滚动条继续提示当前位置。
- 文字组合和右侧开关、状态、箭头适配卡片宽度；深灰图标底座和选中项开关保留对比度。
- 固定页脚中的取消按钮保留独立位置，避免被共享弧形列表重新定位。

共享组件为 `ui_liquid_selection`，最多 16 个操作对象、每个缓存最多 12 个文字对象。绘制复用既有卡片，缩放通过几何尺寸完成，不增加整卡缩放帧缓冲。

## 设备接口

`ui_devices_page_register_connection_port()` 注册非阻塞的 `scan` 和 `connect(kind)` 请求端口。设备类别包含手机、心率带、手表、功率计、速度/踏频。

- 扫描行调用扫描端口，设备行调用对应类别的连接端口。
- 接受请求不等于连接成功；真实状态通过 `ui_devices_page_set_status()` 在 UI 线程更新。
- 状态更新保持当前选中设备。端口未注册时显示未接入反馈，不模拟连接成功。
- 本轮完成页面、选择交互和类别级请求端口；具体设备地址列表、蓝牙扫描协议、配对和断线重连仍由后续通信模块实现。

## 导航与骑行共用会话

| 当前骑行状态 | 点击路线预览的“开始导航” |
| --- | --- |
| 尚未骑行 | 保存路线意图，进入现有搜星准备页，等待 GO |
| 搜星/准备完成 | 继续等待 GO，不单独启动导航或另建记录 |
| 正在骑行 | 启动导航，复用当前记录会话 |
| 已暂停 | 启动导航，沿用当前记录并保持暂停 |
| 正在结束/保存或存在未保存记录 | 提示先完成收尾，禁止新建会话 |

GO 提交记录启动请求；收到成功 ACK 后，现有骑行状态机进入记录状态，再验证预览路线编号和版本并启动导航。等待 ACK 期间不按普通准备态撤销启动，以免后端已记录而 UI 返回首页。

- 骑行页和导航页切换不停止或重建记录。
- 到达本身仍继续记录；点击“完成导航”或确认“结束导航”统一停止并保存骑行，成功后进入骑行总结。确认页取消保持原骑行/暂停状态。
- 结束骑行收到后端 ACK 后发送导航 STOP，同时沿用原有历史保存流程。
- 导航 STOP 失败会提示重试，记录仍独立保存；不因导航通信失败丢弃骑行记录，也不伪造成功。
- 重复 GO 和重复开始导航不会排队启动多份记录。骑行启动失败恢复 GO/取消，允许重试。

## 搜星准备的取消

- 搜星中：定位中按钮禁用，取消可用。
- 准备完成：同一个 464×226 坞内并排取消和 GO，按钮同高；编码器和触摸均可操作。
- 定位失败：重试和取消均可操作。
- 准备页的本次里程、时间等计数展示归零，实时传感数据继续更新；不改后端原始模型或创建记录，避免显示上一场骑行的计数。
- 硬件 BACK 与取消同语义，回 HOME，不创建骑行记录，清除等待导航的意图。
- `ui_command_service_cancel_fix(id)` 只取消定位请求，清除未派发/当前请求及对应待处理结果；旧完成包不再作用到状态。
- 后端新增可选 `cancel(id, context)` 端口，板端可终止旧定位等待任务；取消准备不要求关闭 GNSS 模块。PC 端已实现释放旧任务，支持立即重新准备。
- GO 已提交等待记录 ACK 时消费 BACK，等待成功或失败结果；失败后恢复取消入口。

## 回归与边界

验收覆盖：首页总览只读和刷新防重复、弧形首末项、固定页脚、动态状态不抢焦点、导航搜星取消、记录启动失败、跨页持续记录、暂停时复用会话、到达后等待用户完成、导航结束统一停止与保存、停止失败和保存失败重试。

真实西安地图流程继续覆盖拖动、长按选点、真实道路图规划、地点检索、候选展开/反转、快速关闭重入和减少动态效果。按住地图时延后应用底图坐标重定位，避免长按期间目标地理位置漂移；导航指引和位置标记仍可更新。选点读取前同步 LVGL 对象布局，避免读取旧缓存坐标。

最终结果和全帧/局部刷新逐像素比对写入本轮验证报告。PC 回归不能替代 STM32 的帧耗时、TF 读取和功耗验收，本轮不承诺真机 60 FPS。
