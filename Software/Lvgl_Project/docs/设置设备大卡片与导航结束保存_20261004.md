# 设置、设备大卡片与导航结束保存

日期：2026-10-04。对应当前 `Software/Lvgl_Project` 软件实现，VERSION 保持 1.4.0。

## 布局和操作

- 设置与连接设备使用相同的 114 px 基准行高、12 px 间距，列表在 y=156～798，同屏约五条完整卡片。底部实际页码或设备请求反馈延伸到 y=838，不为性能叠加信息预留空间。
- 保留轻弧线和实心黄色液体选择，选中高度为基准的 102%，非选中尺寸为 96.5%。主设置与设备页选中卡片宽度为 452 px，居中后左右各留 14 px；列表视口横向扩至 x=8～471，滚动条在外侧保留。横向展开独立于高度，文字不拉伸，图标、主副标题、开关和状态均垂直居中。
- 设置主列表的图标底座从 36 px 增至 44 px，右侧值栏重排；开关没有反馈文字时给辅助说明更多宽度，出现等待/失败时为真实反馈腾出位置。
- 设置共享组件通过 `ui_settings_list_set_row_size()` 在添加条目前设置尺寸；电源、区间等紧凑子页面继续使用原默认行高，避免扩大所有弹窗。
- 编码器首尾停止，设备首项负数边界使用一致的有符号运算，避免逆转时回到末项。只有真实触摸滚动才在松手后选取中心附近条目；自动滚动不重选焦点。
- 设备仍使用既有非阻塞扫描/类别连接接口，接受请求不代表已经连接；实际状态继续由硬件端口提供。

## 统一结束流程

此规则替代此前“结束导航继续骑行”的行为。

| 操作或状态 | 当前行为 |
| --- | --- |
| 导航期间切换骑行数据页 | 同一记录继续，导航会话保持 |
| 到达目的地 | 显示到达页，仍记录；等待用户点完成 |
| 快捷菜单中的结束导航 | 确认“结束本次导航与骑行”，明确说明会停止记录并保存 |
| 确认页取消或 BACK | 返回导航操作，保留正在骑行或已暂停状态 |
| 确认结束，或到达页点完成导航 | 进入原有骑行 STOPPING → SAVING → SUMMARY 流程，不再弹第二份骑行确认 |
| 重复按压/重复确认事件 | 等待既有停止请求，不能重复停止或创建多份历史记录 |
| 记录停止失败 | 回到原骑行/暂停状态，导航仍有效，明确提示重试 |
| 数据保存失败 | 骑行已停止，待保存数据保留，提供重试；不显示已保存 |
| 保存重试成功 | 同一条历史记录提交一次，显示已保存的骑行总结并更新汇总 |

应用通过 `ui_nav_workspace_set_finish_callback()` 统一协调。先收到 `UI_COMMAND_RIDE_FINISH` 成功 ACK，再发送导航 STOP 和原有保存请求；不在用户确认后直接伪造停止/保存成功。应用外的独立导航组件仍可使用原导航 STOP 后端，便于板端和组件测试接入。

导航 STOP 与存储属于独立异步服务。若导航 STOP 失败，骑行数据仍保存，显示导航停止失败反馈并允许重新结束；不因通信失败丢弃记录。真机必须接入记录停止 ACK、历史存储成功/失败结果，不以按钮点击作为落盘证据。

## 绘制开销

连续保存再打开路线的回归暴露了路线大卡片按压缩放的 ARGB 中间图层分配失败。已把大卡片反馈改为 2 px 的平滑按压位移与背景反馈，保留小按钮原效果；该反馈不再申请约 374 KB 的整卡变换缓冲，也未扩大 LVGL 堆预算。

## 验证范围

相关组件回归、应用全帧/局部刷新和真实西安离线导航回归覆盖大行尺寸、文字对齐、首尾滚动、取消、到达完成、暂停会话复用、停止失败、保存失败及重试。画面和审计数据见本轮验收记录；PC 测试不等于 STM32 真机帧率或 TF 卡断电可靠性验证。
