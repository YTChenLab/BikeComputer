| 领域 | 本轮实现及结果 |
| --- | --- |
| 胶囊动效 | 保持当前位置/速度的二阶阻尼控制；焦点拉伸回弹、共享控制面板展开、底部容器连续形变；反向/打断连续；骑行阻尼更高，减少动态效果可直接到位 |

## 验证证据

现有 D 盘 UCRT64 工具链增量构建成功，CTest 32/32 通过。新增覆盖数据契约、硬件输入、配置保存、完整应用流程、骑行布局及部分缓冲刷新；其余回归扩展了存储、状态、地图、动效和报告边界。测试计数按 CTest 用例计算，不等于内部断言数。

首页／个人／设置追加细化后的完整回归仍为 32/32，通过固定模拟输入对比 215 组 FULL/PARTIAL 渲染帧，逐像素一致。新增边界、数据口径、预览与后续限制见 [首页个人主页与设置细化](首页个人主页与设置细化_20261001.md)；此前启动和骑行页文档中的旧帧数保留为对应轮次的历史证据。

用户追加参考图后的最新纯黑／灰／黄视觉与个人页排版见 [黑黄主题与个人主页重构](黑黄主题与个人主页重构_20261001.md)，保留上一轮的数据契约和开机流程。

- 完整应用流程：展开期间关闭、触摸取消、开始→息屏继续计时→暂停冻结→恢复→保存失败→重试成功、开始命令尚未 ACK 时请求关机。
- 数据：UI 不 drain 时统计仍接受提交；重复/倒退时间不累计；心率断连排除；功率 0 计入；过期、时钟环绕、patch 合并/旧包拒绝；首次有效负海拔和累计计数基线。

- 视觉：检查实际 LVGL 的首页、紧凑/展开控制中心、骑行/暂停、待保存、报告及区间编辑器；修正减号回退和报告日期映射。模拟器数值明确来自 DEMO，不能当成硬件测试。

异常掉电前未进入并持久化保存 intent 的活动数据不保证恢复；端口返回 OK 也不能代替介质断电验证。PC 存档读取会验证完整文件，记录规模很大时可在真实适配器中使用带校验索引；UI 异步等待仍保持可操作。
