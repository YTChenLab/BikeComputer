# STM32 固件版本日志

## 2.0.0 · 2026-11-16

状态为初始源码交付基线。版本号依据本目录现有的 v2.0 命名建立，本目录从本条开始维护独立版本记录。

2026-11-17 整理当前正式源码和配套 UI 资源代码，作为首次 Git 交付基线。以下功能描述依据当前源码，完整构建和板级验证仍待完成。

### 当前源码能力

- 使用 STM32H743IITx、Keil ARM Compiler 6 工程和 FreeRTOS 应用任务框架。
- 包含 SDRAM、LTDC、DMA2D、QSPI、ADC、UART、GNSS 和实体输入相关的板级接口。
- 包含输入路由、电源管理、电池状态、GNSS 服务和 STM32 LVGL 启动适配。
- 包含 QSPI A/B 资源存储、资源包校验、资源绑定和 USART1 资源安装协议实现。
- 提供正式 PC 资源安装客户端，支持资源包校验、状态查询、安装、维护与复位命令。
- 通过兄弟目录 Lvgl_Project 构建 UI、LVGL 和 ThorVG 静态库，再由 Keil 链接固件。

### 功能模块说明

- 启动与显示层维护启动状态和故障信息，提供 SDRAM 初始化、LCD 帧缓冲、LTDC 显示与 DMA2D 图形操作接口。
- 输入层采集物理按键和编码器事件，通过输入服务与路由转交 UI 任务。电源服务处理电源事件，ADC 和电池服务提供电池状态接口。
- GNSS 模块通过 UART、DMA 和 NMEA 解析提供定位数据与服务状态。FreeRTOS 任务框架组织系统、输入、GNSS、传感器、通信、存储和 UI 任务。
- QSPI 资源系统实现资源包解析、完整性校验、A/B 槽位管理、资源绑定和安装会话。USART1 安装客户端提供状态查询、安装、取消、维护和重启命令。
- LVGL STM32 适配提供 UI 启动、资源绑定与资源就绪检查，配套资源生成脚本用于生成固件所需的资源描述和静态库。
